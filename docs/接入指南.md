# 接入指南

编辑器有三种接法，可以混用：业务系统的后端用 REST API 建模板、建合同、出文件；前端用 SDK 或 iframe 把编辑器放进自己的页面。

| 接法 | 适合 | 入口 |
| --- | --- | --- |
| REST API | 所有系统的后端（Java、.NET、Go、PHP、Node） | `apps/server`，`/api/*` |
| SDK | 用 npm 打包的前端（Vue、React、Angular 都行） | `@oe/web` 的 `createEditor` |
| iframe 嵌入 | 任何网页，包括 JSP、ASP.NET、PHP 页面 | 嵌入页 `embed.html` + `@oe/web/embed` 的 `connectEmbed` |

## 1. 鉴权

- 业务系统后端：`Authorization: Bearer <API Key>`。API Key 只放在后端，不下发浏览器。
- 浏览器：后端用 API Key 调 `POST /api/tokens` 签一个短时效的文档令牌，前端放在请求头 `X-Document-Token`。令牌绑定文档、模式、用户、字段权限、能不能打印下载，随时可以改权限或吊销。
- 令牌和登录态都不放进任何地址（包括 iframe 的 `src`）。

## 2. REST API

常用接口（完整入参看 `apps/server/src/app.ts` 里各接口的 zod 定义）：

| 接口 | 作用 |
| --- | --- |
| `PUT /api/field-library` | 登记业务字段库（字段 key、名称、类型、数据源、带出关系） |
| `POST /api/templates` | 建模板：`doc`（文档 JSON）或 `docx`（base64，自动转换，返回导入报告） |
| `POST /api/templates/{id}/versions` | 发布新版本（已发布的版本不可改） |
| `POST /api/documents` | 用模板版本 + `values` 建合同 |
| `GET /api/documents/{id}` | 取文档、字段值、状态、版本号 |
| `PATCH /api/documents/{id}/data` | 合并更新字段值 |
| `POST /api/documents/{id}/operations` | 批量操作（插入、替换、改条款、填值），原子执行 |
| `GET /api/documents/{id}/export?format=pdf\|docx\|html\|txt` | 下载；`&version=` 指定版本，对不上返回 409 |
| `POST /api/render` | 模板版本 + 数据直接出文件（`format` 同上），不建合同 |
| `POST /api/convert` | 格式转换，不落库：`docx` → `json`（文档 + 导入报告）/ `pdf` / `docx` / `html` / `txt`；`doc`（文档 JSON）→ `pdf` / `docx` / `html` / `txt` |
| `POST /api/tokens` | 签发文档令牌 |
| `POST /api/documents/{id}/seal-status` | 开始盖章、提交、驳回、作废 |

例：把一份 Word 合同转成 PDF。

```bash
curl -X POST https://editor.example.com/api/convert \
  -H "Authorization: Bearer $API_KEY" -H "Content-Type: application/json" \
  -d "{\"docx\":\"$(base64 -w0 合同.docx)\",\"to\":\"pdf\",\"title\":\"设备采购合同\"}" \
  -o 设备采购合同.pdf
```

例：订单审批通过后出正式合同。

```text
POST /api/documents          { templateId, versionNo, bizKey: "订单号", values: { contractNo, amount, items } }
POST /api/tokens             { documentId, mode: "fill", userId, permissions: { amount: "readonly" } }   → 给业务员填写
POST /api/documents/{id}/seal-status  { action: "start", version }                                         → 进入盖章
GET  /api/documents/{id}/export?format=pdf&version=8                                                      → 归档
```

## 3. SDK（npm 打包的前端）

```ts
import { createEditor } from '@oe/web'

const editor = await createEditor(document.querySelector('#editor')!, {
  mode: 'fill',
  load: async () => (await fetch('/my-backend/contract/123')).json(), // 后端用文档令牌取 GET /api/documents/{id}
  save: async (payload) => { await fetch('/my-backend/contract/123', { method: 'PATCH', body: JSON.stringify(payload) }) },
  request: async ({ url, method, query, body }) => myHttp(url, { method, query, body }), // 远程数据源带自己的登录态
  download: async (format) => { location.href = `/my-backend/contract/123/export?format=${format}` }, // 可选：PDF、Word 走服务端
})

editor.on('field-change', ({ key, value }) => console.log(key, value))
editor.setData({ contractNo: 'HT-2026-0001' })
const blob = await editor.export('docx') // 浏览器里生成，不经服务端
```

句柄的方法：`getData`、`setData`、`validate`、`save`、`isDirty`、`setMode`、`apply`（批量操作）、`find`、`insertText`、`insertField`、`getText`、`export`、`download`、`import`、`print`、`focus`、`on` / `off`、`destroy`。

事件：`ready`、`change`（用户改了内容）、`field-change`（字段值变了）、`saved`、`mode-change`、`dirty-change`、`field-focus`。

## 4. iframe 嵌入（任何网页）

1. 部署嵌入页（`apps/demo/embed.html` 构建后的产物，或自己照 `apps/demo/src/embed.ts` 写一页），比如在 `https://editor.example.com/embed.html`。
2. 业务系统页面里放 iframe，地址上用 `origin` 写自己页面的来源（嵌入页只认这些来源，可写多个，逗号分隔）：

```html
<iframe id="editor" src="https://editor.example.com/embed.html?origin=https://oa.example.com"></iframe>
```

3. 用 `@oe/web/embed` 的 `connectEmbed`（不带 Vue，几 KB）把文档交给编辑器，实现要用的宿主函数：

```ts
import { connectEmbed } from '@oe/web/embed'

const editor = await connectEmbed(document.querySelector('#editor'), {
  origin: 'https://editor.example.com',          // 只认这个来源发来的消息
  mode: 'fill',
  document: await (await fetch('/oa/contract/123')).json(),   // { doc, fields, values, title, permissions, actions }
  host: {
    save: async (payload) => { await fetch('/oa/contract/123', { method: 'PATCH', body: JSON.stringify(payload) }) },
    request: async (req) => oaHttp(req),          // 远程数据源：在父页面发，带 OA 的登录态
    search: async (field, query, page) => ({ items: [], total: 0, pageSize: 5 }),
  },
})

editor.on('dirty-change', (dirty) => { window.onbeforeunload = dirty ? () => true : null })
await editor.setData({ contractNo: 'HT-2026-0001' })
const pdf = await editor.export('pdf')           // Blob
```

方法、事件和 SDK 一样，只是都返回 Promise。宿主函数可以实现 `save`、`publish`、`search`、`request`、`download`、`importDocx`、`onSeal`，没实现的就不用。

安全约定：

- 嵌入页只处理 `origin` 参数里列出的来源发来的消息，第一次初始化之后只认那一个来源；回消息时指定目标来源。
- 客户端只处理这个 iframe 发来的、来源是 `origin` 的消息。
- 文档令牌和登录态不进 iframe 地址；保存、搜索这些在父页面执行。

示例：`pnpm --filter @oe/demo dev` 后打开 `http://localhost:5173/embed-host.html`，左边是一个不用 Vue 的「业务系统」页面，右边 iframe 里是编辑器。

## 5. 文件格式

| 格式 | 浏览器里打开 | 浏览器里下载 | 服务端 |
| --- | --- | --- | --- |
| Word（.docx） | 有（带导入报告） | 有 | 导入（建模板、`/api/convert`）、导出 |
| PDF | — | 有（图片版，不能选字） | 有（带文字层，正式件用这个） |
| HTML | 有（清洗掉脚本、事件属性） | 有 | 有 |
| Markdown | 有 | — | — |
| 纯文本 | 有 | 有 | 有 |
| JSON（文档 + 字段 + 值） | 有 | 有（编辑模式） | `GET /api/documents/{id}` |
| 图片（每页一张 PNG） | — | 有（zip） | — |

令牌关了下载时，界面上没有下载项，服务端 `/export` 返回 403；打印同理。

复选、单选在 Word、HTML、纯文本里写成「☑ 选中的 ☐ 没选的」，SDK 的 `getText` 也一样；PDF、图片照编辑器画。

## 6. 字段值

`values`（REST API 建合同、改值）、`setData` 和 `getData().values.values` 用同一种写法，键是字段 key：

| 字段类型 | 值 | 例 |
| --- | --- | --- |
| 文本、数字、金额 | 字符串 | `"HT-2026-0001"`、`"5200"` |
| 日期 | 显示的文字，按字段的日期格式 | `"2026年11月05日"` |
| 下拉、单选 | 选项的 code（写的时候也认选项文字） | `"stage"` |
| 复选 | 选中的 code 用逗号连起来；写的时候也认数组 | `"ac,parking"`、`["ac", "parking"]` |
| 数据选择 | 显示的文字；带出的字段各有各的值，选中的记录在 `snapshots` 里 | `"苏州工业园区精工机械有限公司"` |
| 表格循环 | 数组，一行一个对象，键是列名 | `[{ "name": "显示器", "qty": "2" }]` |
| 图片 | 图片的 dataURL | `"data:image/png;base64,…"` |
| 计算（金额大写） | 不用传，按来源字段算 | `"伍仟贰佰元整"` |

演示里的 5 份范本（`apps/demo/src/samples.ts`）是现成的写法：字段定义、文档 JSON、样例值都在里面。
